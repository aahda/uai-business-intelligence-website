# Personal Portfolio

Personal academic portfolio website built with React, TypeScript, and Vite.

## Stack

- **React 19** + **TypeScript**
- **Vite** (build tool)
- **Tailwind CSS v4** (styling)
- **i18next** + **react-i18next** (English/Spanish)
- **SimpleIcons CDN** (technology logos)

## Features

- Responsive layout with sections: About, Research, Skills, Projects, Contact
- Dark / Light mode with persisted preference
- Language switcher (English / Spanish)
- Project image lightbox with zoom and pan
- Skills grid with auto-falling technology icons

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
